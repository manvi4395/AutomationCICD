
# E-Commerce Cart Automation Project 

This repository contains an automation testing framework designed specifically for testing the shopping cart functionality of an e-commerce application. The framework aims to provide reliable, scalable, and maintainable test scripts for ensuring the robustness and accuracy of the cart's features and workflows.

- Built using the Page Object Model (POM) for better code reusability and readability.

Automated Test Coverage:
- Add and verify products to cart
- Select country and place order
